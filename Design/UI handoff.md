# Stacks UI handoff

Everything a designer needs to redesign the Stacks interface, and what to send
back so it can go straight in.

## How the UI is built (read this first)

There are no image files. Every knob, button, card, display and block is drawn
by code (JUCE, a C++ framework) from a handful of colours and sizes. So there
is nothing to "export in the format we use": the format is code. What exists
and can be handed over:

- **Screens** — `screens/` holds every screen of the plug-in rendered at 2x
  (3000 x 1720 px for a 1500 x 860 window) with a real preset loaded. These are
  the reference for what exists today. They are regenerated by a tool in the
  repo (see the end), so they are always current.
- **Colour tokens** — the whole palette is 15 named colours (table below). A
  `theme.json` with new values recolours the entire UI with no code change.
- **Sizes** — the layout constants are listed below.

## What to send back

Any of these go straight in, in order of how little work they need:

1. **`theme.json`** — new colours for the tokens below. Drop-in; nothing else
   changes. Hex `rrggbb` or `aarrggbb`, any subset of keys.
2. **Mockups per screen**, PNG or Figma, at **1500 x 860** (or 3000 x 1720 for
   2x). Keep the same screen set and names as `screens/` so each mockup maps
   to a screen. The drawing code is then rewritten to match: knob shape,
   card shape, strokes, shadows, spacing, type sizes. Measurements are taken
   from the mockup, so build it to pixel sizes, not loosely.
3. **SVG for shapes** (optional, if you prefer to draw rather than describe):
   one SVG per control state, artboard the size of the control, named like
   `knob-idle.svg`, `knob-hover.svg`, `knob-modulated.svg`,
   `switch-on.svg`, `switch-off.svg`, `combo.svg`, `tab-active.svg`,
   `button.svg`, `button-bright.svg`, `card.svg`, `link-on.svg`,
   `link-off.svg`, `tile.svg`, `block.svg`. These are used as the exact
   reference for the code (and an SVG loader can be added so they are read at
   runtime if iterating as files is preferred).

What cannot be delivered as files: layout logic, animation (the blocks falling
onto the slab, the construction animation while a sound grows), and anything
that reacts to the sound. Describe those in words or a short video and they are
built to match.

Keep the window at **1500 x 860** unless there is a reason to change it; the
plug-in is fixed-size.

## Colour tokens

| Key | Default | Used for |
|---|---|---|
| background | `111316` | window background |
| panel | `191c20` | the Lab panel, section bands |
| card | `22262b` | every section card, tiles, combo boxes |
| accent | `5cb8ff` | the active tab, the Evolve button, selected block, links |
| accentDim | `1d3447` | accent wash behind selected things |
| text | `e8ebee` | primary text, knob indicators |
| muted | `7c8591` | captions, inactive tabs, hints |
| outline | `2c3137` | card and control borders |
| rowSound | `f5a524` | OSC A/B/C, MIX, SAMPLE accent (amber) |
| rowFilter | `ff6f61` | FILTER, CHARACTER, envelopes (coral) |
| rowMovement | `3fd1c4` | MODULATORS, VOICE, ARP (teal) |
| rowSpace | `5c9dff` | EFFECTS (blue) |
| rowShape | `c07cf0` | DISTORTION, COMPRESSOR arcs (violet) |
| rowMacro | `ffd166` | MACROS page (gold) |
| rowSample | `9ad17b` | SAMPLE knobs (green) |

Each synth row wears its colour: the vertical band at the left of the row, the
knob arcs in that row, the active tab underline. Modulation sources have their
own fixed colours (LFO 1-4 teal/blue/lilac/pink, envelopes, macros) drawn as
dashed arcs around a modulated knob.

`theme.json` goes in `~/Music/Stacks Patches/` and is read at launch, e.g.

```json
{ "background": "15161a", "card": "272a33", "accent": "ffb24a", "rowSound": "f2a541" }
```

## Type

Font: "Avenir Next" "SF Pro Display" "Helvetica Neue" (first one found on the Mac; no custom font files are bundled).
Sizes in use: 30 bold (home heading), 24 bold (growing heading), 14 and 12.5
regular (body, hints), 11 bold uppercase letter-spaced (section titles, tabs),
10 regular (knob captions).

## Layout constants (logical px, window 1500 x 860)

| Thing | Size |
|---|---|
| Header | 44 high: logo, Home/Synth switch, preset name, scope, spectrum, tuner, Auto-tune, undo/redo/settings, master knob |
| Keyboard | 58 high, 88 keys |
| Lab panel (right) | 392 wide |
| Synth page tabs | row of text tabs under the header, 2 px underline in the row colour |
| Section card | title strip 17 high, padding 5, gap between cards 6, corner radius 6 |
| Row band | 14 wide vertical colour band with the row name, left of each row |
| Knob cell | 62 x 70: knob (margin 7) above a 13 px caption; hover swaps the caption for the value |
| Display cell | 60 high (wavetable 3D, filter curve, envelope, LFO shape, step lane) |
| Effects row | cards in chain order, 22 px gap carrying the link (arrow + switch circle); drag a card by its title strip |
| Home tiles | 7 tiles in a grid, colour dot + name + blurb, hover lift |
| Blocks (Lab and Home) | isometric slabs, skewed top face, name on the front face; the seed slab is wider |

## Control inventory (states to design)

- **Rotary knob**: idle; hover (caption shows the value); modulated (dashed
  arc in the source colour outside the value arc); assign mode (ring in the
  source colour, click to connect); macro-assigned.
- **Linear slider** (Variation): track, thumb, filled part.
- **Tabs**: text, inactive muted, active in the row colour with an underline.
- **Text buttons**: normal (card fill, outline), bright (accent fill, dark
  text), small round "<" / "..." / grip.
- **Toggle** (Design wavetables): square check.
- **Combo box**: card fill, chevron, popup menu with the same palette.
- **Text editor**: preset name field in the header.
- **Scrollbar**: thin, muted.
- **Section card**: title, "..." more button, drag grip (effects only), link
  switch between effects (on: filled accent dot with arrow; off: hollow,
  dashed arrow, the next card dims to 45 %).
- **Displays**: 3D stacked wavetable frames, filter response with fill,
  envelope curve, LFO shape (drawable), step lane (16 bars), scope and
  spectrum in the header, tuner strip.
- **Home**: tiles; the growing screen (slab, construction animation, blocks
  falling and bouncing into place, "listening / sketching / shaping / tuning"
  progress words); results (five blocks on the slab, Grow / Save / Open the
  synth buttons, Close / Medium / Far variation).
- **Lab**: STACKS (blocks), HISTORY (family tree), LIST (cards), LIBRARY
  (folder rows, preset rows with category and tag chips, heart, Play).
- **Keyboard**: 88 keys with octave labels; a pressed key in the accent.

## Regenerating the screens

```bash
cmake --build build.nosync --target StacksUiKit
./build.nosync/StacksUiKit_artefacts/Release/StacksUiKit Design/screens 2
```

A third argument names a preset JSON to load instead of the factory pad.
